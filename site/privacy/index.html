Control room notice

Privacy

Effective 27 August 2026

The website sends no analytics or advertising requests. It loads no remote fonts or third-party runtime scripts.

The browser model runs in memory. Demo changes use a separate demo: browser key and are removed when you leave.

CLI data

The CLI reads the Collector config and sample paths you provide. It sends bounded sample bodies only to your selected test endpoint.

Endpoints stay on loopback unless you pass --allow-remote. The CLI creates no persistent telemetry copy and does not edit your Collector config.

Offline cache

A service worker caches public site files. This lets the documentation and browser model reopen offline.

Outside demo mode, the site stores no form inputs. Clear the site's browser data to remove the cache and demo key.

Hosting logs

The host may process short-lived security and access logs to deliver the site.

The site sets no cookies or browser identifiers. It adds no authorization or custom identity headers to requests.

Questions

Open an issue in the project source repository for privacy questions. Do not attach production telemetry or secrets.
