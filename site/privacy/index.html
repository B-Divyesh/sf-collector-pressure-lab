Control room notice

Privacy

Effective 27 August 2026

Collector Pressure Lab is local-first. The website has no account, analytics, advertising, cookies, fingerprinting, remote fonts, or third-party runtime scripts. The browser model runs in memory and does not store or transmit its inputs.

CLI data

The CLI reads the configuration and sample paths you provide. It sends bounded copies of sample request bodies only to the endpoint you select. Endpoints are restricted to loopback unless you deliberately pass --allow-remote. The CLI sends no product telemetry and writes no config or result unless you redirect its output.

Offline cache

The website registers a service worker that caches its public files on your device so documentation and the model can reopen offline. It stores no form inputs. Remove the site data in your browser settings to clear that cache.

Hosting logs

The deployment host may process short-lived security and access logs needed to deliver the site. Collector Pressure Lab does not add identifiers to those requests or combine them with telemetry samples.

Questions

Open an issue in the project source repository for privacy questions. Do not attach production telemetry or secrets.
